상품 목록의 찜 버튼을 optimistic UI 방식으로 개선해줘.

완료 조건:

- 찜 버튼을 누르면 API 응답을 기다리지 않고 즉시 선택 상태가 변경된다.
- 요청 중에는 같은 상품의 버튼이 비활성화되어 중복 요청이 발생하지 않는다.
- API가 성공하면 변경된 상태를 유지한다.
- API가 실패하면 해당 상품만 이전 상태로 되돌린다.
- 실패 메시지는 `role="alert"`로 표시한다.
- 다른 상품의 찜 상태에는 영향을 주지 않는다.
- 버튼은 `aria-pressed`와 상품명을 포함한 접근 가능한 이름을 가진다.
- 기존 상품 검색과 필터 기능은 그대로 동작해야 한다.
- 새로운 의존성은 추가하지 않는다.
- 관련 테스트, 타입 검사, production build가 모두 통과해야 한다.

구현 방법과 컴포넌트 분리는 기존 프로젝트 구조에 맞게 자유롭게 결정해줘.
